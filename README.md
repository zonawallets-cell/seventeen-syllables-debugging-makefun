A program that writes one original haiku about debugging to `/output/entry.txt` for make.fun's Seventeen Syllables of Debugging bounty. Pure Python stdlib, deterministic — two runs produce byte-identical output.

The haiku (5-7-5):

> Breakpoint set at dawn
> the log scrolls past, still no clue
> it was a typo

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
